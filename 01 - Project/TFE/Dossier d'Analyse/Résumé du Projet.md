Le but de ce TFE est de développer une application de gestion de cartes à collectionner
L'application sera tournée entièrement vers l'aspect collection du hobby et pas vers l'aspect "jeu", la base d'utilisateur sera donc uniquement des collectionneurs, les aspects plus orienté vers le "jeu" à proprement parler sont donc dans le hors périmètre du projet
L'application servira entre autre à : 
- Centraliser sa collection (plusieurs jeu de cartes disponibles)
- Ajout de cartes à la collection (avec différentes informations sur la carte (état etc))
- Préconstruire un classeur
- Système de recherches et de filtres parmi toutes les cartes d'un jeu disponible
	- Visualisation par set possible
- Système de wishlist
- Système de statistique
	- Récupération des valeurs des cartes
